# 睿扬光电展示站 UI 与动效规范

Status: Active design contract
Date: 2026-08-07
Applies to: 新的南京睿扬光电公开展示 Demo

## 1. 目的与适用边界

本文是新展示前台在设计和开发期间共同使用的视觉与交互合同。首页、产品详情、应用、AI 选材以及以后通过准入审批的新页面保持同一品牌语言；产品目录页以当前版本为冻结基线，不纳入本轮内容或动效改造。

本轮的首要边界是保留既有页面布局：不得增加、删除、合并、重排页面区块，不得改变网格、分栏、卡片位置、信息数量、区块顺序或功能关系。除在既有图片框内部加入 floating organic blob animation with smooth morphing deformation 外，只允许校正文案和替换更准确、权属清楚的插图。

本规范不适用于现有 Chemical Trade Copilot。旧系统继续遵循 `docs/UI_STYLE_GUIDE.md`，两套界面不得混用组件、色彩或产品结构。

第一版仍是用于验证品牌、产品理解、材料浏览、公开证据和售前交互的展示 Demo，不是完整企业官网或企业级系统。

## 2. 已批准的体验方向

方向名称：**Daylight Optical Lab｜日光光学实验室**。

目标感受：

- 明亮、精密、通透，有光学材料特征；
- 大留白、少文字，页面首先让用户愿意继续浏览；
- 动效由滚动和操作触发，持续背景保持缓慢克制；
- 概念视觉负责吸引，真实产品、参数和来源负责建立可信度；
- 高级感来自连续响应、层次和细节，不来自大面积纯黑、霓虹光晕或堆叠特效。

页面不得出现面向设计或开发人员的解释，例如“这不是一张首屏”“每项能力显示来源与状态”“无法核验的内容不包装成承诺”。证据规则应由组件状态和来源入口自然表达。

## 3. 短期 Demo 信息架构

短期 Demo 现有五种页面模板如下。该表用于说明当前页面任务，不是永久页面上限，也不授权重新设计现有布局：

| 页面 | 主要任务 | 核心体验 |
|---|---|---|
| 首页 | 建立品牌、理解业务并进入下一步 | 光谱文字、实时光学背景、材料旅程 |
| 产品目录 | 按材料、工艺或应用寻找产品 | 搜索、筛选、产品卡重排、比较入口 |
| 产品详情 | 看懂参数、形态、来源和询价条件 | 材料透镜、参数光轨、证据抽屉 |
| 应用 | 从波段或器件理解材料方向 | 光路连接、应用切换、背景色域变化 |
| AI 选材 | 从需求目标形成候选与询盘 | 追问、光路收束、候选卡和结构化结果 |

产品目录页完全冻结：布局、文案、图片、数据、搜索、筛选、环形画廊、比较入口、拖动手感、转场和其他交互均保持当前版本，不为承接其他页面而新增状态或入口。

当前品质与证据进入首页信任区和产品详情来源抽屉，联系功能使用全站可打开的技术询盘侧栏。未来只有在独立客户任务与真实内容量足够时，才允许把制造能力、质量/计量、技术资源、细分应用或公司/研发内容拆成新页面。

### 3.1 新页面准入与复用顺序

新增页面必须先完成只读调研，不得从空白设计或自研技术开始：

1. 先证明有独立客户任务，且现有页面、锚点、抽屉或详情模板无法清楚承载；
2. 先盘点当前导航、版式、卡片、参数、证据、询盘和动效组件，能够复用时不得另建同类组件；
3. 再核对成熟同行的官方页面、现成设计模式、维护中的开源实现与官方技术文档；
4. 技术选择顺序为直接复用、采用成熟方案、薄层适配、最后才自建；自建必须有固定失败案例证明前三者不足；
5. 外部方案必须核对维护状态、许可证、依赖体积、移动端、无障碍、性能和静态回退，不因一个视觉效果引入整套框架；
6. 新页必须有足量可核验内容和企业可公开素材，不能用占位文案、重复图片或概念视觉拼成空壳页；
7. 每页单独写明客户任务、参考来源、复用资产、导航位置、验收标准与回退方式，并先制作隔离 URL 预览；
8. 用户明确批准前，不增加正式路由、导航入口或默认页面。

所有获批新页面必须继续使用本文的字体、色彩、留白、圆角、导航、公司内容主线、证据等级、图片门禁、organic blob 边界及可访问性规则。参考成熟经验只吸收任务组织和经过验证的模式，不照搬对方品牌视觉、文案或代码。

## 4. 全站结构

### 4.1 顶部主导航

顶部导航始终承担可发现性，不得被图标 Dock 替代。

- 左侧：公司 Logo 与英文名称；
- 中部：材料、产品、应用、品质、AI 选材、联系；
- 右侧：搜索、中英文切换、技术询盘；
- 桌面端滚动后由实白转为轻微半透明，但文字对比度不得下降；
- 窄屏折叠为品牌、搜索和菜单按钮。

### 4.2 辅助导航边界

- 第一版不设置常驻侧边栏或侧边 Dock；
- 顶部主导航承担全站去向，章节内仅在确有必要时使用简短进度刻度；
- 进度刻度不承载第二套导航，不遮挡图片、正文、滚动条或操作入口。

## 5. 视觉令牌

### 5.1 色彩

| 令牌 | 建议值 | 用途 |
|---|---:|---|
| Pearl | `#F7F8F5` | 全站主背景 |
| Snow | `#FFFFFF` | 导航、内容面板和产品卡 |
| Glacier | `#EAF5F8` | 光学区块和浅色过渡 |
| Mineral Ink | `#11151A` | 标题和主要按钮 |
| Slate | `#5F6870` | 正文与辅助信息 |
| Rule | `#DDE4E3` | 细分隔线和卡片边界 |
| Spectral Cyan | `#58D6E8` | 光谱渐变与交互进度 |
| Spectral Violet | `#8275E8` | 光谱渐变与 AI 路径 |
| Warm Photon | `#E5B46A` | 材料高光和光谱末端 |
| Verified | `#27745E` | 已核验来源状态 |
| Pending | `#9A6B20` | 官网公示或待复核状态 |

黑色只可用于材料对象内部、图片遮罩或局部对比舞台，不得再作为整段品质区或连续多个视口的背景。任何局部深色舞台都必须被明亮留白包围。

### 5.2 实时背景色域

动态背景由 Pearl、Glacier 和低透明度光谱色组成。

- 光谱层透明度建议为 `8%–20%`；
- 单次循环 `18–30s`，缓入缓出，不出现明显首尾跳点；
- 指针只影响光源中心位置，位移不超过容器尺寸的 `3%`；
- 页面失焦、滚出视口或设备性能不足时暂停持续动画；
- 不使用高饱和全屏渐变、随机颜色闪烁或无限粒子背景。

各页面当前色域定义如下；本轮不调整这些页面底色或背景结构：

- 首页：冰蓝、青、淡紫和少量暖金；
- 产品目录：接近白色，以冰蓝作为筛选反馈；
- 产品详情：根据材料类别选择一个主色，参数区保持中性；
- 应用页：随波段或应用在蓝、青、紫、暖金之间连续过渡；
- AI 选材：初始多色，随着条件明确逐步收束为候选材料色。

### 5.3 字体

- 中文标题：优先使用现代无衬线黑体，字重 `600–750`；
- 英文标签、化学式和数字：Inter、Segoe UI 或系统无衬线；
- 大标题紧凑，正文舒展；不得为了“科技感”使用难读的窄体或装饰字体；
- 参数数字使用等宽数字特性 `font-variant-numeric: tabular-nums`；
- 常规内容标题最多两行；滚动叙事中的展示标题可以拆为三段，但必须作为一个清晰语义整体；首页首屏说明中文建议不超过 40 字；
- 正文禁止大段居中排版。
- 展示标题可根据场景采用横排、竖排、斜排、分行错位或弧线路径，但每幕只选择一种主导方式；
- 竖排优先用于短产品名或两至八字关键词，弧排优先用于短标签，不用于参数、来源、正文或操作入口；
- 斜排角度应与产品轮廓、膜层或光路方向一致，不使用与构图无关的随机旋转；
- 无论标题如何编排，正文、关键参数和主操作保持水平且可快速扫读。

### 5.4 留白与尺寸

- 桌面最大内容宽度：`1240–1320px`；
- 常规章节上下留白：`104–136px`；
- 平板：`80–96px`；手机：`56–72px`；
- 同层级卡片间距：`12–20px`；
- 圆角以 `16–28px` 为主，不把所有小元素都做成胶囊；
- 每个章节只保留一个主标题、一个必要说明和一个主动作。

## 6. 核心动效语言

第 6.1–6.7 节只记录既有或此前已批准的动效语义，本轮不授权新增、重排或改写这些交互。当前唯一允许新增的动效是第 6.8 节，并且只能进入符合条件的既有图片框。

### 6.1 滚动驱动的光谱文字

名称：**Scroll-scrubbed spectral text reveal**。

- 标题初始使用 Mineral Ink 或低对比灰；
- 光谱从左到右或沿光路方向穿过字形；
- 着色进度与原生滚动位置一一对应，反向滚动可恢复；
- 光谱经过后可以保留轻微色差，也可回落到深色，具体由页面任务决定；
- 只用于每页一至两个关键标题，不用于正文、导航或参数表；
- 不自动循环闪烁，不用逐字弹跳代替颜色渲染。

### 6.2 实时光学背景

名称：**Pointer-reactive optical mesh / caustic field**。

- 使用缓慢 Mesh Gradient、柔焦光斑和轻微焦散纹理表达光学环境；
- 背景持续运动幅度小，明显变化由滚动和指针触发；
- 鼠标接近材料对象时，光源中心向对象偏移；
- 背景永远不抢夺文字对比度，不让用户感到页面在持续晃动。

### 6.3 材料透镜

名称：**Material inspection lens**。

- 指针经过材料图时出现局部圆形或椭圆形检测透镜；
- 透镜内可显示放大纹理、化学式、纯度、波段或形态中的一项；
- 单次只突出一个信息，点击后进入产品详情；
- 触屏改为点击热点，不依赖悬停。

### 6.4 参数光轨

名称：**Guided parameter light rail**。

- 产品详情滚动时，一条细光线连接材料对象与参数列；
- 光线到达某项参数后，数值、单位、适用条件和来源入口依次出现；
- 参数本身必须可直接阅读，动画关闭后一次性完整显示；
- 不用仪表盘、虚构百分比或装饰性大数字。

### 6.5 产品共享元素转场

名称：**Shared-element product transition**。

- 从产品卡进入详情时，产品图从原位置连续放大到详情舞台；
- 返回时反向还原，并保留筛选条件和滚动位置；
- 动画失败或用户减少动态效果时使用普通页面导航；
- 不使用整屏黑场、翻转页面或与材料无关的复杂 3D 转场。

### 6.6 AI 光路收束

- 初始展示多条低透明度候选光路；
- 用户完成一个追问后，排除的路径淡出，保留路径变清晰；
- 最终候选材料卡从光路终点形成；
- 动画只解释筛选过程，不暗示真实模型推理或确定性推荐。

### 6.7 策展式场景转场

- 同一段滚动叙事中的相邻场景不得复用同一套“上下位移、缩放、虚化”进出场；
- 每幕只设置一个主动作，允许聚合成形、斜切展开、层片错位、弧线穿场、扫描建立或档案收拢；
- 离场动作必须把上一幕的材料、光路、膜层或信息结构交给下一幕，不做与内容无关的翻页和旋转；
- 场景容器不统一施加模糊。需要景深时仅作用于远离焦点的次要图层，正文和产品主体保持清晰；
- 反向滚动应自然反演运动，快速滚动时不得出现长时间空白、多个标题叠加或图片停留在半屏；
- `prefers-reduced-motion: reduce` 下取消路径、旋转和视差，只保留即时显隐与完整静态构图。

### 6.8 有机浮动图片框

名称：**Floating organic blob animation with smooth morphing deformation**。

- 该效果是既有图片框内部的动态遮罩，不是新的页面结构、卡片组件或全屏液体背景；
- 适用于首页、产品详情、应用和 AI 选材中确有主视觉作用的既有图片框；产品目录页完全排除；
- 图片框的外层占位、中心点、宽高边界、与文字的相对位置和所属网格必须保持不变；形变只能发生在固定边界内，不得推动文字、改变分栏或造成布局抖动；
- 运动表现为低频漂浮、连续柔和的轮廓形变和轻微的指针响应，不使用弹跳、爆炸、快速旋转或高频水波；
- 同一视口只保留一个主要 blob 动效焦点；其余图片使用更弱的相位、静态有机遮罩或原图，避免所有元素同时晃动；
- 优先复用首页现有 OGL Flowmap、透明有机遮罩和统一的可见性调度；不得为该效果重复创建多个无管理的实时画布，也不新增只为形变服务的通用动画依赖；
- `prefers-reduced-motion: reduce`、低性能设备、离开视口、页面失焦、WebGL/JavaScript 或资源失败时，回退为同尺寸的静态有机裁切或完整静态图；
- 真实产品主体不得因形变被持续遮断，参数、标签、来源和操作入口不得放进会形变的遮罩内。

## 7. 功能型高级交互

### 7.1 材料比较托盘

- 从页面底部浮出薄型玻璃托盘；
- 最多比较三种材料；
- 只比较当前公开资料可以支持的纯度、波段、形态和来源；
- 底部比较托盘显示已选数量；
- 关闭后不改变产品筛选结果。

### 7.2 证据抽屉

- 正文旁只显示简短的“来源”或状态标记；
- 点击后从右侧展开来源名称、发布日期、适用范围和核验状态；
- 状态分为“政府文件已核验”“公司官网公示”“待企业复核”“概念演示”；
- 不在正文重复解释证据治理原则；
- 环评或项目公示不得表现为已投产能力，官网自述不得表现为独立认证事实。

### 7.3 技术询盘侧栏

- 从顶部按钮、产品卡或产品详情均可打开；
- 自动带入用户正在查看的材料和已经选择的条件；
- 第一版只形成结构化预览，不自动发送邮件或写入外部系统；
- 关闭后保留当前页面状态。

## 8. 各页面动效编排

### 8.1 首页

- 保留当前首页的区块顺序、左右关系、文字位置、热点位置、三张叠放图片卡、按钮位置和既有交互；
- 只允许校正品牌定位、热点名称与辅助说明，替换更能对应公司能力且权属清楚的图片；
- 首页右侧现有实时 Flowmap 继续作为主动态焦点；后续既有图片框可采用第 6.8 节的 organic blob，但不得借此重排页面；
- 第二屏保留当前三卡叠放的数量、位置、尺寸、倾角和文字区位置，只替换图片、标题、说明以及图片内部遮罩；
- 首页能力入口只指向现有页面或锚点，不要求产品目录增加筛选状态、面包屑或新布局。
- 首页材料产品入口是已批准的单一区块布局例外：左侧只读复用目录中的类别、名称、化学式、摘要、最多八项数值字段和来源层级，右侧提供 DyF₃、CVD ZnSe、Ge 三个可访问选择器；底部单独动作进入完整目录，不复制筛选、拖拽、环形画廊或目录 URL 状态；
- 该入口使用左侧珍珠白到右侧淡冰青的连续背景，并复用首页既有 `--mx`、`--my` 与青色径向环境光；上下边缘不得以不透明底层截断全局光场，移动端改为静态闭合渐变；
- 产品图只使用 `1px` 冷灰半透明发丝边、约 `7px` 小圆角和极弱环境阴影；不得恢复白色夹层、粗边、大圆角、明显浮起阴影或产品图后的装饰性圆圈/椭圆轨道；
- 首页正文区使用原生纵向文档流，不使用 sticky 分镜、整屏吸附、滚轮劫持、交叠淡化或按滚动隐藏内容。

### 8.2 产品目录

- 本页完全保持当前版本，不修改布局、文案、图片、数据、搜索、筛选、卡片、环形画廊、比较入口、拖动手感、背景、转场或链接；
- 本页不加入 organic blob，也不因首页或其他页面改动而新增承接状态；
- 后续验收仅用于确认本页未发生回归，不把本页列为改版预览。

### 8.3 产品详情

- 保留当前布局、参数区、证据入口和主操作关系；
- 只校正文案与插图，并可在既有主图片框内部加入 organic blob；
- 不显示无依据的价格、库存、MOQ 或交期。

### 8.4 应用

- 保留当前布局、区块顺序、应用切换和页面去向；
- 只校正文案与插图，并可在既有图片框内部加入 organic blob；
- 不虚构客户案例或未经证实的应用结果。

### 8.5 AI 选材

- 保留当前布局、追问顺序、候选卡数量、交互和结果结构；
- 只校正文案与插图，并可在既有图片框内部加入 organic blob；
- 最终结果仍不得声称完成工程选型。

### 8.6 指定保留区块

- `G:\桌面\屏幕截图 2026-08-05 145423.png` 是 Technical Contact 区块的样式基线：保留深青色大圆角底板、左文案与双按钮、右侧 `2 × 2` 联系信息矩阵，以及它们的比例、位置和层级；仅允许必要的文案或联系方式校正。
- `G:\桌面\屏幕截图 2026-08-05 145318.png` 是 Research Focus 区块的样式基线：保留浅色大圆角底板、左侧说明、右侧 `2 × 3` 能力矩阵、分隔线，以及它们的比例、位置和层级；仅允许必要的能力名称与说明校正。
- 这两个区块是信息面板，不是图片框；不得强行加入 organic blob，也不得借内容校正改变卡片数量、网格或按钮位置。

### 8.7 以后获批的新页面

- 页面类型不预先锁死，但必须先通过第 3.1 节准入；
- 优先从现有页面令牌、导航、区块和组件组合，不创建独立设计系统；
- 信息顺序仍遵循“客户任务—公司能力—事实证据—适用边界—下一步动作”；
- organic blob 只进入既有/获批设计中的主图片框，不作为新页面成立的理由；
- 每次只审看一个新增页面，避免多个未验证页面同时扩大范围。

## 9. 图片与公司元素

- 所有图片必须服务“材料基础—制备/加工/镀膜—检测/测量—器件与应用支持”公司主线；仅仅好看、具有科技感或适合 blob 形变，不构成选用理由；
- 公司 Logo、真实产品图和公开联系方式必须来自公司官网或企业确认素材；
- 六张生成图只能标记为概念视觉，不能描述为真实设备、厂房、产品照片或测试结果；
- 概念图与真实产品图应在同一页面共存，前者负责氛围，后者负责产品识别；
- 来源标记保持简短，详细说明进入证据抽屉；
- 图片需有真实替代文本，不能只写“image”或堆关键词。
- 图片取景由主体轮廓、运动方向和可用负空间决定，可使用圆形、环形、斜切、梯形、弧形、胶囊或无框构图；
- 不得将所有素材强制塞入同一圆角矩形，也不得用 `object-fit: cover` 裁掉产品主体；
- 真实产品必须完整可辨，概念视觉可以局部裁切，但裁切必须强化光路或材料姿态；
- 同一视口只保留一个主要异形轮廓，其余信息使用安静的矩形或无框布局，避免形状互相竞争。
- 本轮不得重新决定图片框在页面中的位置、尺寸或所属网格；只可在既有框内换图、调整不损害主体的取景，并按第 6.8 节加入 organic blob。
- 产品目录页的图片与图片框不属于本轮可调整范围。
- 每张主图必须与相邻标题一一对应，并明确属于材料对象、制备/加工/镀膜、检测/测量或器件/应用中的一类；无法明确归类的图片不进入页面；
- 图片选用优先级固定为企业确认实拍/产品原图、可核验资质或检测资料、明确标注的概念视觉；不得让概念视觉压过真实能力证据；
- 产品照只能证明产品存在，不能单独证明研发、生产、镀膜、检测或质量控制；上述主张必须有相应工序、设备、在制品、检测资料或人员操作图承接；
- 禁止无关实验室图库、泛科技光效、第三方 Logo/水印、权属不明设备图、低清截图、重复图片承担不同能力，以及用 organic blob 遮盖错配或低质量素材。

## 10. 文案规则

- 所有文案必须服务“材料基础—制备/加工/镀膜—检测/测量—器件与应用支持—技术需求沟通”主线；偏离公司真实业务的漂亮句子必须删除；
- 先说具体材料、能力、应用和客户能完成的动作，不说设计过程；
- 每个主要区块必须依次回答：公司能做什么、凭什么可信、客户因此获得什么、下一步去哪里；
- 公司优势优先表达为业务覆盖、技术承接、质量可核验和技术需求沟通效率，不使用脱离证据的自我评价；
- 删除无关解释、空泛使命、重复口号和自我评价；
- 删除“请滚动”“滑动不是跳页”“滚动叙事用于理解”“搜索和筛选不被动画阻碍”等交互说明；交互方式应由布局、状态和运动本身被理解；
- 一个章节只表达一个卖点；
- 产品页优先使用名称、化学式、规格、形态、应用和来源；
- 表达品质时使用具体质量体系、检测环节、参数条件、资质年份和来源状态，不单独使用“品质卓越”“实力雄厚”“专业可靠”；
- `2011`、`5000+㎡`、团队背景、ISO 9001、知识产权体系、高新技术企业等事实必须逐项核对来源、年份和适用范围，不得拼接成“行业领先”或“全产业链”；
- 应用文案必须回扣公司可提供的材料、加工、镀膜、检测或测量能力；AI 选材文案不得把候选方向写成确定性工程结论；
- 中文与英文必须保持同一技术含义和承诺强度；
- 事实无法核验时，减少主张而不是增加免责声明；
- “概念演示”只在必要位置和页尾简洁出现，不反复打断浏览。

内容的客户留存目标是“吸引—理解—信任—行动”：首屏快速建立业务认知，后续区块用连续能力与品质证据降低工程判断风险，最后以明确技术需求入口推动询盘。禁止用虚假稀缺、制造焦虑、自动弹窗、强迫留资或含义不清的按钮增加停留。

## 11. 响应式、可访问性与降级

- 所有交互均可使用键盘完成，并有清晰焦点样式；
- 不依赖颜色或悬停传递唯一信息；
- 触屏使用点击热点和必要的底部操作栏，不依赖悬停反馈；
- `prefers-reduced-motion: reduce` 下取消背景连续漂移、固定滚动、弧形缩放和大幅共享元素转场；
- `prefers-reduced-motion: reduce` 下 organic blob 停止连续形变，回退为同尺寸静态有机遮罩或完整静态图；
- 动画关闭、资源失败或脚本未加载时，正文、参数、来源和询盘入口仍完整；
- 动态文字着色必须保持可读对比度，不使用透明文字等待动画填充；
- 页面缩放至 `200%` 时主要内容和操作仍可使用。

## 12. 性能约束

- 首屏不默认加载完整产品库或多个重型 3D 场景；
- 持续动画优先使用合成友好的 `transform` 与 `opacity`；
- 离开视口的循环动画暂停，页面失焦时停止；
- 同一时刻只允许一个主要滚动舞台和一个持续背景成为性能焦点；
- 多个既有图片框需要 organic blob 时必须共享调度并按可见性启停，不为每张图片无上限创建独立持续渲染循环；
- 第一版不默认引入 Three.js。只有批准效果无法用 CSS、SVG、图片分层与滚动编排实现时再单独评估；
- 动效不得阻塞导航、产品检索、参数阅读或询盘操作。

## 13. 第一版验收标准

- 首页、产品详情、应用和 AI 选材的区块顺序、网格、分栏、卡片位置、信息数量、按钮位置和功能关系与当前版本一致；
- 产品目录页与冻结基线一致，文案、图片、数据、筛选、环形画廊、拖动手感、链接、转场和其他交互均无变化；
- 两个指定截图区块保持原布局与样式，只存在经过核对的内容校正；
- 首页第二屏仍为原三卡叠放构图，替换后的图片、标题与说明能分别对应真实产品或能力；
- 首页、产品详情、应用和 AI 选材的替换内容均能归入“材料—工艺—检测—器件/应用—技术沟通”主线；
- 每个主要内容区块同时具备能力主张、相邻证据、客户价值和明确下一步，不能只有口号或装饰图；
- 品质表达全部落到可核验的体系、检测、参数条件、资质年份或来源状态，空泛品质形容词和未经支持的领先性承诺为零；
- 每张主图与相邻文案一一对应，企业实拍/产品原图优先，产品照不冒充工艺或检测证据，概念图不冒充真实能力；
- 获准页面中适合的既有图片框体现 floating organic blob animation with smooth morphing deformation，且所有形变都被限制在固定外层占位内；
- 非图片信息面板不强行使用 blob，同一视口不出现多个争抢注意力的持续形变；
- 所有替换文案与图片都有来源或企业确认依据，不通过视觉包装扩大能力主张；
- 桌面、窄屏、键盘操作、减少动态效果、资源失败和低性能回退通过真实浏览器验收；
- 所有改动先存在于隔离网页预览，用户逐页批准前不回写正式页面。
- 如有新增页面，存在可核验的独立客户任务和充足内容，已记录成熟参考、现有资产复用、外部方案评估、导航位置及回退方式；
- 新页面与现有站点使用同一视觉令牌、内容主线、证据门禁和交互降级，不出现第二套风格或重复组件。

## 14. 明确不做

- 不建设全量企业官网、CMS、账号后台或生产数据库；
- 不接入真实模型、RAG、CRM、ERP 或自动邮件；
- 不设置常驻侧边 Dock；
- 不使用滚动劫持、自定义鼠标、背景音乐、无限粒子或整站持续 WebGL；
- 不把 organic blob 扩展成整站背景，不套到按钮、参数、联系方式或普通信息卡上；
- 不重新设计既有页面布局，不因统一动效而抹平各页面原有功能差异；
- 不修改产品目录页；
- 不以“高级感”为理由隐藏导航、降低对比度或延迟正文。

## 15. 开发人员使用顺序

1. 先读取根目录 `AGENTS.md`、`CURRENT_WORK.md` 和 ADR 0001；
2. 以本文作为新展示前台的 UI 与动效实现合同，并先执行布局冻结与产品目录排除规则；
3. 不修改或复用旧 `docs/UI_STYLE_GUIDE.md` 的产品规则；
4. 新页面或新功能先盘点现有实现，再调研成熟同行、开源方案与官方文档，完成复用/采用/适配/自建比较；
5. 先在隔离预览中校正文案与插图，再只向既有图片框逐层加入 organic blob；
6. 每个动效同时实现移动端与减少动态效果降级；
7. 未达到第一版验收标准前，不扩建企业级能力。
